PROJECT PAGE FILES

This package preserves your existing homepage CSS and adds two dedicated project detail pages.

1. Install router in your existing project: npm install react-router-dom
2. Copy src/main.jsx and src/HomePage.jsx into your existing src folder.
3. Copy src/pages/NagaShawls.jsx and src/pages/CampusPlus.jsx into src/pages/.
4. Copy src/project-pages.css into src/.
5. Keep your existing src/styles.css and assets/nagaShawl.jpeg and assets/campus.png.
6. Run npm run dev and test the View Project buttons.

Routes:
/
/projects/naga-shawls
/projects/campus-plus

Note: CampusPlus details are intentionally limited to what is currently described on the homepage; add confirmed features and a repository URL when available.
